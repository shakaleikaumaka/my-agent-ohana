# AI Attribution

This project is built by humans working with a disclosed team of AI agents (the "ʻohana") running on the Taurus platform. See also [`AI-USAGE.md`](./AI-USAGE.md) (Tokyo era).

## What agents do
- Draft code, tests, docs, and scripts.
- Run test suites and health checks, and report the results as they are, including failures.
- Prepare issues, checklists, and research notes.

## What humans decide (agents never do these)
- Product direction, scope, and which prize tracks to enter.
- Merging to `main`, tagging releases, and submitting to ETHGlobal.
- Anything involving money, keys, wallets, accounts, or passwords.
- Anything that publishes a real person's name, image, or voice.

## Commit convention
Commits that an agent substantially wrote carry a trailer naming the agent:
```
Co-authored-by: ohana-agent <NAME> <noreply@myagentohana.com>
```
The human who reviews and pushes is the commit author. Commits made by an agent through the shared bot account start with `by the ʻohana` or say so in the body.
