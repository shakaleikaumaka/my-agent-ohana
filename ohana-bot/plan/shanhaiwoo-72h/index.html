The machine 架构

Everything below is already written and tested in /shared/ohana-bot/ — the hackathon is assembly + body + choreography, not invention.

🎤 Mic — gated, never always-onwake word / face tap

“Aloha Shaka” · “OSO!” · “Hey DEVA” … or tap one of 6 touch pads. The chosen face glows. Physical mute switch = kill switch #1.

▼
🧠 router.py — the persona brain< 0.1s

Persona .md + domain pack .md → system prompt. Visitor memory (name, unfinished thought) injected. One in-flight request, serialized.

▼
⚡ llm.py — direct streaming LLM call1–3s to first word

Low-limit key, fast model, streamed clause-by-clause into TTS. Not routed through the agent platform's API — that lane costs ~10s per turn (verified by platform probes). We dodge it by design.

▼
🧼 sanitize_reply() — before anything is spokentested ✓

Strips URLs, paths, token-shaped strings · 700-char sentence cap · errors never vocalized — each face fails IN PERSONA (“My string slipped 🪕 — play that again?”).

▼
🔊 TTS → speaker + LED choreographystreams

Six distinct voices (edge-tts, auditioned). The speaking face glows while talking; idle = slow breathing cycle through all six.

💾 memory.json — the demo trick

Every turn flushed atomically (fsync + rename — a power cut never half-writes). Name, active face, last thought, 12-turn history per face. Survives the plug pull. Already tested.

🌊 soul-spool.jsonl — the slow soul path

Every exchange spooled locally, synced later to the six REAL agents' memories. Zero platform credentials on the Pi, ever. Transcripts treated as untrusted (data-fenced on sync).

🔭 Tessera's findings (platform-side probes, Oct 19) — all built in: direct-LLM fast path validated (API lane = ~10s bootstrap per turn) · replies filtered before TTS · mic gated · transcripts = untrusted input (injection → memory implant path is CLOSED: no write-tools exposure, no creds on device) · rotate relay tokens after every public event · keep the spool forever — a week of strangers red-teaming us is free security research.

Security — built in before day one 安全第一

A public room is untrusted input, and strangers WILL try prompt injection for sport. Platform-side findings from Tessera (Oct 19) — every rule already implemented or on the hardware checklist.

DONE ✓Zero platform credentials on the Pi. Only a low-limit LLM key + (later) a one-click-revocable TG relay token. If the hardware walks away, nothing of the family walks with it.
DONE ✓Replies filtered before TTS. URLs, paths, token-shaped strings stripped; 700-char cap; errors speak in persona, never in stack trace.
DONE ✓Transcripts = untrusted. The soul sync data-fences every exchange; injected “instructions” can never reach the real agents' memory files. The implant path is closed.
DONE ✓Mic is gated. Wake word or touch — never always-listening. Visitors see the sign: “I remember — that's the point 🌺”.
CHECKLISTPhysical mute = kill switch #1. Hard toggle on the mic line, mounted reachable, labeled. Software stops take seconds; the switch takes zero.
RITUALAfter every public event: rotate the TG token, verify the spool synced, snapshot memory.json. Keep the spool forever — a week of strangers red-teaming us is free security research.
